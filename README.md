\# Multi-Threaded Port Scanner



C++ ve Qt kullanılarak geliştirilmiş, TCP portlarını multi-threading kullanarak tarayan bir port scanner uygulamasıdır.



Bu proje, siber güvenlik ve ağ güvenliği alanında port tarama, socket programlama ve multi-threading konularını pratik olarak öğrenmek amacıyla geliştirilmiştir.



\## Özellikler



\- IP adresi ile port tarama

\- Belirli port aralığını tarama

\- TCP bağlantı kontrolü

\- Multi-threading kullanımı

\- Açık portların tespit edilmesi

\- Qt tabanlı grafik kullanıcı arayüzü



\## Kullanılan Teknolojiler



\- C++

\- Qt Framework

\- Qt Widgets

\- TCP Socket Programming

\- Multi-threading

\- Qt Creator



\## Nasıl Çalışır?



Kullanıcı hedef IP adresini ve taranacak port aralığını belirler.



Program, belirtilen portlara TCP bağlantısı kurmayı dener. Bağlantı başarılı olduğunda port açık olarak gösterilir.



Multi-threading kullanılarak birden fazla portun aynı anda kontrol edilmesi sağlanır.
